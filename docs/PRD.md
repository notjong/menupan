# PRD — Excel 구동 카페 메뉴판

## 1. 목적

카페 점주가 **Excel만 수정·저장해서** 매장 메뉴판 화면(모바일·태블릿·사이니지)을 바꿀 수 있게 한다. 코드를 수정하지 않고 메뉴, 가격, 품절, 테마를 바꾼다.

이 프로젝트는 강의 앵커 예제이기도 하다. "데이터(Excel)와 표현(템플릿)의 분리" 원칙을 한 화면에서 보여주는 것이 목표다.

## 2. 사용자

| 사용자 | 목표 |
|---|---|
| 점주(편집자) | Excel에서 메뉴·가격·품절을 바꾸고 저장하면 바로 화면에 반영되기를 원한다 |
| 고객(열람자) | 매장 사이니지·태블릿·모바일에서 현재 메뉴와 가격, 품절 여부를 읽는다 |
| 수강생(개발자) | 데이터와 표현 분리, 파일 감시, SSE 구조를 학습한다 |

## 3. 기능 요구사항

### F1. Excel 시트 → 메뉴판 페이지

- `_`로 시작하지 않는 시트 1개가 메뉴판 페이지(탭) 1개가 된다. 시트 이름이 페이지 이름이다.
- 시트를 추가하면 페이지가 자동으로 늘어난다.
- 첫 행은 헤더다. 열: `메뉴명`, `가격`, `설명`, `품절`, `카테고리`.

### F2. 메뉴 항목 표시

- 가격은 숫자로 입력하고, 화면에는 천 단위 콤마와 `원`을 붙여 표시한다(예: `4,500원`).
- `품절`이 `Y`면 취소선, 흐림, "품절" 라벨로 표시한다. 빈칸이면 판매 중이다.
- `카테고리` 열로 한 페이지 안에서 소제목 그룹을 나눈다.

### F3. `_설정` 시트

| 항목 | 값 예시 | 의미 |
|---|---|---|
| 매장명 | 빌런 커피 | 화면 상단 매장명 |
| 테마 | cafe-dark | 사용할 테마 ID |
| 자동전환초 | 0 | 0이면 수동 전환, 양수면 그 초마다 페이지 자동 전환 |

### F4. 저장 시 즉시 갱신

- Excel을 저장하면 열린 모든 브라우저 화면이 새로고침 없이 갱신된다.
- 저장(Ctrl+S) 전 변경은 반영되지 않는다. OneDrive 자동저장이면 저장 즉시 반영된다.

### F5. 테마 교체

- 같은 데이터에 CSS와 배경·테두리 PNG만 바꿔 다른 디자인을 적용한다.
- 테마는 `_설정`의 `테마` 값으로 고른다.

### F6. 디바이스 대응

| 디바이스 | 기준 해상도 | 비고 |
|---|---|---|
| 모바일 | 1080×2160 | 1열 |
| 태블릿 세로 | 1440×1920 | 1열 |
| 태블릿 가로 | 1920×1440 | 2열 |
| 사이니지 세로 | 1080×1920 | 키오스크 전체화면, 자동 전환과 함께 사용 |

## 4. 비기능 요구사항

- 저장 후 화면 반영까지 1초 이내(디바운스 300ms 포함)를 목표로 한다.
- 메뉴판은 읽기 전용 단방향 표시다. 화면에서 데이터를 편집하지 않는다.
- 로컬 실행(`npm start`) 하나로 동작한다. 별도 DB나 빌드 단계가 없다.
- UI는 `.claude/rules/anti-ai-slop.md`를 따른다.

## 5. 범위 밖

- 주문·결제, 화면에서의 메뉴 편집, 사용자 인증
- 다중 매장, 다국어

## 6. 확장 아이디어 (강의용, 1차 범위 밖)

- 템플릿 CSS를 추가해 테마 늘리기
- 사내 파일서버의 menu.xlsx를 HTTP 폴링(ETag)으로 갱신
- 키오스크 전체화면에서 `자동전환초`로 페이지 순환

## 7. 인수 조건

1. `npm start` 후 `http://localhost:3000`에서 커피·디저트·음료 페이지가 보인다.
2. Excel에서 가격을 바꾸고 저장하면 1초 안에 화면 가격이 바뀐다.
3. `품절`에 `Y`를 넣고 저장하면 해당 항목이 품절 표시로 바뀐다.
4. 새 시트를 추가하고 저장하면 페이지 탭이 하나 늘어난다.
5. `_설정`의 `테마`를 바꾸고 저장하면 디자인이 바뀐다.
6. `자동전환초`를 5로 바꾸면 5초마다 페이지가 넘어간다.
